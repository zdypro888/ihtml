# 受管后台工具调用

`agent.TaskRuntime` 是与引擎、HTTP 接口和业务领域无关的 goroutine 执行器。它包装已有 Handler，不运行任意源码，不替模型规划业务步骤，也不改变原接口是同步返回还是只受理异步业务的事实。

宿主为每个可信会话创建独立运行时，并通过 `TurnRequest.Tasks` 传入。ihtml assistant 可通过 `Config.Tasks: &agent.TaskConfig{}` 自动管理生命周期。Eino 适配器会暴露四个公共原语：

| 工具 | 作用 |
| --- | --- |
| `task_start` | 提交已发现原工具的名称和完整原参数，立即取得句柄 |
| `task_read` | 读取指定句柄的真实状态/结果；不指定句柄时只列元数据 |
| `task_wait` | 完成通道唤醒，可等任意一个或全部；等待超时不取消调用 |
| `task_cancel` | 请求协作取消，真实终态在 Handler 返回后产生 |

AI 根据用户目标、前置数据和资源冲突选择直接调用、同轮并行或后台调用，以及何时等待/读取/取消。系统提示不指定任何业务接口的执行顺序。

## Go 底层能力

- `Start` 冻结调用并执行已有 Handler，保留可信 invocation 身份。相同会话/轮次/调用键不能改变参数或重新执行。
- `Done` 提供单次调用的完成 channel，`Completed` 提供不含参数和结果的终态通知流，`OnComplete` 可接入宿主通知。
- `Read`、`Wait` 和 `Cancel` 均检查会话 scope 及当前可见工具；scope 由可信会话/权限快照生成，不能由模型选择。
- `EndTurn` 在正常收尾时解除当前轮次的取消绑定，已接纳调用继续受会话和自身期限约束；错误/显式停止取消原轮调用。assistant 的显式停止同时取消该会话尚未返回的后台调用。
- `Close` 取消并等待真正退出，随后关闭通知 channel。Handler 必须响应 context；完成回调不能同步关闭自身运行时/会话。

默认最多 8 个 Handler 同时执行、128 个保留句柄、每结果 64 KiB、单次调用期限 10 分钟。原参数限制 64 KiB，每次读取最多 8 个结果，单次等待最多 30 秒；这些是资源边界，不是业务编排规则。宿主可以配置执行器额度；原 API 的数量、权限及业务配额继续生效。结果超限明确失败/未知，不截断后声称成功。

## 确认、回执和通知

Eino 的后台入口复用原工具的发现、原生批准及副作用防重放边界。直接与后台方式之间不能绕过相同调用的去重；原生批准在创建执行任务之前挂起。

assistant 包装的 Handler 仍执行原实时权限守卫。签名确认工具首先返回真实待确认提案，这次准备调用的返回不是业务执行成功。用户批准后，只对模型原先选择了后台模式的确切调用使用同一个执行池，保留父句柄关联；验签、nonce 消费、实时权限、业务 Handler、持久回执和续办复用原路径。批量批准的后台回执全部保存后才放行原来的自动续办。尚未进入 Handler 的队列取消/超时会释放原卡的排队预留，用户可显式重新批准；新的调度尝试不复用旧 cancelled 句柄，实际写入仍受原一次性 nonce 与业务 invocation 约束，不自动重试。

`task_complete` 是会话级通知，只含句柄、工具名和调用终态，不含参数、凭据或原结果。通知不启动/结束模型轮次。前端显示一个可更新提示，并向宿主事件回调转发；宿主可接入站内通知。

`completed` 仅表示 Handler 返回；原结果中的 pending、accepted 或后台业务状态仍由 AI 根据原工具契约解释。错误、取消、panic 或结果超限若可能已产生外部影响，状态保留为 `unknown`，执行器不自动重试。

## 生命周期边界

这些句柄与结果缓存属于会话内存，支持同一会话跨正常轮次读取；启用 assistant 后台会话时，断线重连保留同一个执行器。它们不替代业务服务的持久任务、幂等记录或数据库回执。会话结束或进程重启后，旧句柄不能恢复；不得据此重放副作用，应核对原业务记录。
